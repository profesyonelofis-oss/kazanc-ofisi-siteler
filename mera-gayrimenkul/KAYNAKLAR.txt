EMLAK ATÖLYESİ ŞABLONU — KAYNAKLAR

Site tek dosyadır (index.html); CSS ve JavaScript sayfanın içindedir.
Açılışta üç saniyelik isim tanıtımı, ardından tek sahnede evin odaları
fare tekerleğiyle ilerler. Akış yalnız fare tekerleği (ve eşdeğeri
dokunma/klavye) ile ilerler; sayfa kaymaz. Çalışırken hiçbir CDN, font
servisi, harita veya API çağrılmaz.
